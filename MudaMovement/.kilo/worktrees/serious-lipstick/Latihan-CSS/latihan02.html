Latihan CSS Background

1. Background Image & Opacity

Section ini menggunakan gambar sebagai background.

kontainer ini menggunakan opacity ; 0,85, sehigga teks dan background kontainer ini menjadi sedikit transparan terhadap gambar utama di belakangnya.

CSS : background-image : url (...)
CSS : Opacity : 0.85

2. Color, Repeat, & Size

Section ini menggunakan background-color biru dengan gambar pola (pattern) transparan.

Pola tersebut diatur agar mengulang ke seluruh arah (repeat)dengan ukuran asli (size : auto)

kotak di ataws mendemostrasikan background-size.containdi dalam kontainer yang memilki warna background berbeda.

CSS : background-color : #3498db
CSS : background-repeat : repeat ;
CSS : background-size : auto | contain | cover

3. Background Position

Disini kita menggunakan gambar abstrak yang ukurannya diset manual (800px) dan no-repeat.

Gambar tersebut diposisikan secara spesifik di kanan bawah section ini.

CSS : background-position :right bottom;
CSS : background-repeat : no-repeat;

4. Background Attachment (Fixed)

ini adalah efek favorit banyak desainer :**Parallax**

Coba scroll halaman ini naik dan turun. Gambar background di section ini diam (fixed) ditempatnya,

sementara konten teks diatasnya bergerak melewati gambar.

CSS : background-attachment : fixed ;
CSS : background-size : cover ;
